# Портфолио Fullstack-разработчика | Рустам Яруллин

Интерактивный сайт-портфолио, созданный для демонстрации опыта и пет-проектов. Сайт выступает центральным хабом, объединяющим мои работы на разных технологических стеках в едином, эстетичном и производительном интерфейсе.

## Технологический стек

- **Framework:** Vue 3 (Composition API)
- **Сборка:** Vite
- **Анимации:** GSAP + ScrollTrigger (для сложных скролл-эффектов)
- **Стилизация:** Tailwind CSS
- **Качество кода:** ESLint + Prettier

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
